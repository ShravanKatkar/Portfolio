CineSense — Enterprise Hybrid AI Movie Recommendation & Grounded RAG Assistant

A full-stack, production-grade cinema intelligence platform over 10,000+ titles featuring a 2-stage hybrid recommendation pipeline (5 algorithmic tiers fused via RRF & MMR) coupled with an autonomous ReAct AI Agent with a 0% hallucination guarantee.

  • 10K+titles
  • 5ranking tiers
  • 64latent factors
  • Two-stage recsys: ALS Matrix Factorization (64 latent factors), Item-Item CF, Neural Semantic Embeddings (kNN), TF-IDF, and Bayesian Popularity.
  • Candidate ranking fused via RRF and diversified with Maximal Marginal Relevance (MMR).
  • Autonomous ReAct agent powered by Groq Llama 3.3 70B with candidate whitelist grounding.
  • Dual-tier caching with Redis 7 & in-memory TTL plus live telemetry feedback loop.
  • Built with React 19, Vite, Tailwind CSS, FastAPI Python 3.12, and PostgreSQL 16 + pgvector.
